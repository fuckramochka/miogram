# ✦ Mioplugin — Офіційний репозиторій та SDK плагінів Miogram ✦

Ласкаво просимо до **Mioplugin** — офіційного середовища розробки та каталогу плагінів для **Miogram**.

Плагіни в Miogram дозволяють розширювати функціонал месенджера без модифікації вихідного коду:
- Перехоплювати та модифікувати вихідні та вхідні повідомлення.
- Додавати власні пункти в контекстні меню повідомлень, чатів, профілів та бокового меню (Drawer).
- Перехоплювати будь-які внутрішні методи Telegram/Android через нативне хукання (Xposed-style API).
- Створювати інтерактивні налаштування прямо в інтерфейсі клієнта.
- Розробляти як на **Python 3.11** (швидке прототипування, багаті бібліотеки), так і на **Rust / WebAssembly** (`.mioplugin` для максимальної швидкості та захисту).

## 🚀 Швидкий старт: створення першого плагіна

Кожен Python-плагін — це файл `plugin.py` або архів із маніфестом.

Мінімальний приклад плагіна:

```python
from base_plugin import BasePlugin
from android_utils import show_toast

__id__ = "my_first_plugin"
__name__ = "Мій перший плагін"
__description__ = "Простий плагін для демонстрації можливостей Mioplugin"
__author__ = "@your_username"
__version__ = "1.0.0"

class MyPlugin(BasePlugin):
    def on_plugin_load(self):
        self.log("Плагін успішно завантажено!")
        show_toast("Привіт від Mioplugin! ✦")

    def on_plugin_unload(self):
        self.log("Плагін вивантажено")
```

## 🛠️ Як встановити плагін у Miogram

1. Відкрийте **Miogram** -> **Налаштування** -> **Плагіни**.
2. Натисніть **+** (Додати плагін) або відкрийте файл `.py` / `.mioplugin` прямо в чаті.
3. Додаток автоматично валідує плагін, створить ізольоване оточення та увімкне його.
4. Керувати налаштуваннями плагіна можна прямо зі списку встановлених плагінів.
