# LumiGram — ядро vs докачування

Принцип: вбудоване = критичний шлях (рендер, протокол, приватність, старт, OTA, БД).
Докачуване = важке / рідкісне / персональне / часто оновлюється / потребує мережі.
Движок плагінів не міняємо: докачуване їде через існуючі дозволи (`PluginPermissions.java`):
`messages.read` (пілюлі/фід), `network` (погода/курси/тексти), `files` (паки/моделі),
`settings` (пресети), `ui` (екрани). `hooks`/`native` — тільки своєму.

## ВБУДОВАНЕ — без цього ніяк (ядро APK)

1. **OTA-скелет** — `updater/GitHubUpdater.java`: канали, `.part`+розмір, FileProvider. Без нього нема доставки докачуваного.
2. **Навігація-скелет** — нижня панель/drawer/планшет/back, папки-скелет, лічильник. Все інше спирається на це.
3. **Список чатів база** — архів, пошук, сторіс-перемикач (сам рендер), FAB, міні-аватарки.
4. **Повідомлення база** — хвостик, фон відповідей, деталі, edited→іконка, онлайн-індикатор, меню-скелет, широкі пости (простий layout).
5. **Приватність-ядро** — Ghost пакети (не читати/не в мережі/без typing), підтвердження посилань, движок чистки трекінгу (без самого файлу), DNS/проксі-движок, False Bottom каркас.
6. **Сховище-ядро** — папка Downloads, кеш-движок, експорт/імпорт налаштувань каркас, Cloud-скелет (upload/restore/clear).
7. **Пуші/батарея/діагностика**, Crashlytics opt-in, ContentCapture-перемикач, OSM/Google каркас.
8. **Камера база** — один шлях Telegram + HD-перемикач; PiP/автопауза база.
9. **Плеєр база** — повний/міні, черга/шафл/швидкість/перемотка (без текстів).
10. **Переклад база** — кнопка в меню + цільова мова (без адаптерів).
11. **Pill-скелет** — `pillstack/PillRegistry.java`, порядок/drag, схованка. Системні пілюлі RAM/CPU/DC-пінг/кеш/проксі — вбудовані (без мережі, 0 дозволів).
12. **Feed-скелет** — таймлайн/лічильник/архівні (читає існуючі канали, своєї мережі нема).
13. **AyuMoments-движок** — хуки видалення/редагування + БД + дата прочитання (глибокі хуки, не винести).
14. **Зовнішність-скелет** — радіуси, секції, дільники, blur-перемикач, M3-каркас, Monet-каркас (без самих палітр).

## ДОКАЧУВАНЕ — плагін/пак/модель/пресет

1. **Pill-джерела (мережа)** — `WEATHER, BTC/ETH/USD/EUR/GOLD, ExchangeRates`: погода (гео+карта, 15 хв), крипта/золото/курси. Причина: мережа, ключі, часті зміни. Права: `network`. GHOST/LAST_SEEN — лишити в ядрі.
2. **Вигляд-дані** — Icon packs `.icons`, App-іконки, Emoji-сети, Monet-палітри, Lumi-теми `.lumitheme`. Чисті дані, важкі, смакові. Права: `files`+`ui`.
3. **Vosk-моделі** — десятки–сотні МБ на мову, 99% юзерів треба 1–2. Вже докачуються — так лишити. Права: `files`.
4. **AdGuard tracking filter** — оновлюється частіше за реліз. Движок в ядрі, файл — докачуваний.
5. **AI-пресети** — моделі/ролі/ендпоінти/температура JSON-ом. `AiController` в ядрі, список — докачуваний. Права: `settings`+`network`.
6. **Тексти пісень** — LRCLIB/lrcmux адаптери. Падають, міняють API. Права: `network`.
7. **Перекладачі-адаптери** — DeepL/Gemini/Groq/OpenAI/OpenRouter. Ключі юзера + квоти. Права: `network`+`settings`.
8. **Inline-математика валюти** (`@calcmulabot`) — зовнішній бот-курс. Права: `network`.
9. **Last.fm** — скраблінг у музику профілю, приховані байти, перезалив треку. Ламке — окремо. Права: `network`+`files`.
10. **Glyph-модуль цілком** — тільки Nothing Phone. 99% пристроїв не треба. Окремий `.plugin` з перевіркою моделі.
11. **CameraX-розширення** — зум-слайдер, стабілізація, широкий кут, FPS. Натив, треба не всім.
12. **Фільтри-дані** — regex-набори, блок-листи каналів, імпорти закладок/Ayu-БД. Дані, не код.
13. **HDR-превʼю** — device-specific, окремим модулем.

## Що НЕ виносити (частi помилки)
- Ghost-пакети, видалені-хуки, підтвердження посилань — це приватність/цілісність, мають бути в ядрі й аудититись.
- OTA, Cloud-скелет, експорт налаштувань — довіра, не плагін.
- `hooks`/`native` стороннім не давати (див. `PluginPermissions.isDangerous`).
